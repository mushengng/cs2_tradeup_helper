# CS2 汰换（Trade Up）组合助手

一组用于 CS2 汰换合同磨损计算的 Python 小工具，包含**反解材料平均磨损**和**暴搜 10 材料组合**两个脚本。
全程使用 `decimal` 高精度十进制运算，**纯标准库、零第三方依赖**。


## 关于材料选择功能的当前限制说明

目前，本脚本在选择材料时，仅支持使用同一种枪皮。

更准确地说：只要材料的磨损最小值与最大值相同，即可视为可互相使用的同类材料。因此，当前实现并不是严格限制“必须为同一款枪皮”，而是要求参与选择的材料具有相同的磨损上下限。

受当前能力限制，若要在选择材料时支持更灵活的情况，需要用户输入较多参数。这对用户来说过于麻烦，使用体验较差，因此该功能暂时搁置（咕咕咕）。

后续如有能力优化参数输入方式，再考虑完善该功能。

## 功能

| 脚本 | 作用 |
| --- | --- |
| `src/material_avg_wear_solver.py` | 已知材料/产物的磨损区间和目标产物磨损，反解出**材料所需的平均磨损** |
| `src/target_combo_finder.py` | 给一批材料（磨损 + 价格），遍历 `C(n, 10)` 个组合，筛出产物磨损匹配目标的组合，按总价升序输出最便宜的 10 组 |

## 计算原理

单个材料的归一化磨损：

```
normalized_i = (wear_i - material_min) / (material_max - material_min)
```

产物磨损 = 10 个材料归一化磨损的**平均值**映射到产物区间：

```
product_wear = product_min + (Σ normalized_i / 10) × (product_max - product_min)
```

## 环境要求

- Python 3.9+（开发使用 3.13）
- 无需安装任何第三方包

## 脚本一：反解材料平均磨损

```bash
python src/material_avg_wear_solver.py
```

### 用法

1. 先自己选择好要合成产物所需的某种材料
2. 查询该产物与材料的最小/最大磨损值
3. 根据提示输入所需参数

### 输入示例（数值仅作演示）

```
请输入材料最小磨损: 0.06
请输入材料最大磨损: 0.80
请输入产物最小磨损: 0.00
请输入产物最大磨损: 0.50
请输入产物最终磨损: 0.12345678901234567

```

### 输出示列（数值仅作演示）

```
计算得到的材料平均磨损为: 0.24271604773827159
```

## 脚本二：搜索最优组合

```bash
python src/target_combo_finder.py
```
### 注意事项

CS2里，枪皮的磨损值是**离散**的，相邻两个值之间**存在间隔**

例如，磨损值 0.1314520537853241 的下一个磨损值为 0.1314520686864853 ，而非 0.1314520537853242

因此，通常情况下只能保证 **7** 位的精度

### 用法：

1. 根据**脚本一**计算得出的平均磨损值，去交易平台上寻找并记录下数个材料的磨损值。（建议上下浮动不超过 **0.01**）
2. 根据提示信息输入所需要的参数
3. 输入材料，按每行 `磨损值 价格` 的格式输入，输入 `空行` 结束材料的输入，最少 **10** 个、最多 **30** 个。（当匹配位数为 **7** 时，材料数量建议不超过 **25** 个，否则运行速度过慢）
4. 计算完成后**按成本价升序**输出十个组合，可按照组合中的编号去刚刚的记录中找出对应的十个材料，去交易平台购买

### 输入示例（数值仅作演示）

```
【第一步】请输入材料磨损范围：
材料最小磨损值：0
材料最大磨损值：1

【第二步】请输入产物磨损范围：
产物最小磨损值：0
产物最大磨损值：0.7

【第三步】请输入目标最终磨损值：
目标最终磨损值：0.1314520  

【第四步】请输入需要匹配的小数位数：
需要匹配的小数位数（1-17）：7
将按「截断到7位小数」的规则匹配组合！

【第五步】请输入材料列表（最多30个材料）：
请输入材料磨损值（17位小数）和对应价格（格式：磨损值 价格，每行一组）：
示例：0.12345678901234567 100.5
最多可输入 30 个材料，输入空行结束输入

材料1 / 30 (磨损 价格，直接按Enter键结束): 0.18778008222579956 0.45
材料2 / 30 (磨损 价格，直接按Enter键结束): 

...
```
